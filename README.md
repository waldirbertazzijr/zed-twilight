# Zed Twilight

[TextMate's Twilight](https://github.com/textmate/themes.tmbundle/blob/master/Themes/Twilight.tmTheme) theme for [Zed](https://zed.dev).

![twilight](./screenshots/twilight.png)

## Themes

- **Twilight** — the default. The original palette with text colors lightened just enough to be comfortably readable.
- **Twilight (Darker)** — the default with a darker line-number gutter.
- **Twilight (Classic)** — the original tmTheme colors, untouched.
